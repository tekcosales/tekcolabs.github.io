Cloud data control

Users may permanently delete all encrypted cloud backup data at any time from within DropSpot by opening Settings → Reset cloud backup. This deletes encrypted backup records and uploaded photos from cloud storage while leaving local data on the device untouched unless the user chooses otherwise.
